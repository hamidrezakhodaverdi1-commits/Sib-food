# سیب فود — راهنمای ساخت APK فقط با گوشی

## بررسی فایل اکسل نمونه
فایل نمونه دو برگه «سفارش» و «فاکتور روز» دارد. برگه سفارش ستون‌های محصول، تعداد، قیمت و مجموع را دارد؛ مجموع از ضرب تعداد در قیمت به‌دست می‌آید. برگه فاکتور روز ستون‌های محصول، تعداد فروش، قیمت میانگین و مبلغ کل را دارد. برنامه این منطق را اجرا می‌کند و میانگین قیمت را به‌صورت وزنی (مجموع مبلغ تقسیم بر مجموع تعداد) محاسبه می‌کند. اطلاعات نمونه به برنامه وارد نشده و فهرست کالاها در نصب اولیه خالی است.

## ساخت APK با GitHub از گوشی
1. در مرورگر گوشی وارد github.com شوید و وارد حساب خود شوید.
2. دکمه + را بزنید و **New repository** را انتخاب کنید.
3. نام مخزن را `hesabyar` بگذارید، حالت **Public** یا **Private** را انتخاب و **Create repository** را بزنید.
4. فایل ZIP پروژه را از حالت فشرده خارج کنید. در صفحه مخزن، **Add file → Upload files** را بزنید.
5. همه فایل‌ها و پوشه‌های داخل پوشه `hesabyar` را انتخاب و بارگذاری کنید؛ خود پوشه مادر را به‌عنوان یک پوشه تو در تو آپلود نکنید. پوشه مخفی `.github` و فایل workflow باید حتماً بارگذاری شوند. اگر انتخاب فایل‌های متعدد در مرورگر دشوار است، از اپلیکیشن GitHub یا قابلیت Desktop site مرورگر استفاده کنید.
6. پایین صفحه **Commit changes** را بزنید.
7. در مخزن وارد زبانه **Actions** شوید. گردش‌کار **Build Hesabyar APK** را انتخاب کنید. اگر اجرا خودکار شروع نشده، **Run workflow → Run workflow** را بزنید.
8. پس از پایان موفق، روی اجرای سبزرنگ بزنید. پایین بخش **Artifacts**، مورد `SibFood-debug-apk` را انتخاب کنید تا ZIP حاوی APK دانلود شود.
9. فایل دانلودشده را با برنامه مدیریت فایل گوشی باز و از حالت فشرده خارج کنید. فایل `app-debug.apk` را اجرا کنید.
10. اگر اندروید اجازه نصب نداد، در پیام سیستم برای همان مرورگر/مدیر فایل گزینه **Allow from this source / اجازه از این منبع** را فعال کنید و نصب را ادامه دهید.

## امکانات و نکات
- اپلیکیشن بومی اندروید (Kotlin)، بدون WebView و بدون نیاز به اینترنت هنگام استفاده است.
- کالاها و ردیف‌های فروش در پایگاه داده SQLite گوشی ذخیره می‌شوند.
- تغییر نام کالا پس از فروش، فروش‌های قبلی را تغییر نمی‌دهد؛ ردیف‌های فاکتور بر اساس نامی که هنگام ثبت سفارش ذخیره شده گروه‌بندی می‌شوند.
- میانگین قیمت واحد به نزدیک‌ترین عدد صحیح تقسیم صحیح می‌شود؛ مبلغ کل دقیق است.
- خروجی XLSX واقعی و قابل بازشدن در Excel/Sheets است و در Downloads ذخیره می‌شود.
- پاک‌کردن فاکتور با تأیید انجام می‌شود؛ کالاها حذف نمی‌شوند.
- این خروجی APK از نوع debug است و برای نصب شخصی مناسب است. برای انتشار عمومی باید نسخه release امضاشده ساخته شود.

## ساختار
`app/` کد و تنظیمات اپلیکیشن؛ `.github/workflows/build-apk.yml` ساخت خودکار APK در GitHub Actions؛ فایل‌های Gradle تنظیمات Build.
